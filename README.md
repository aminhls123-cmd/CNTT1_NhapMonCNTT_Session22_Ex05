# Bài 5 : Tối ưu quy trình hỗ trợ kỹ thuật nội bộ

## 1. Mẫu Bug Report Template
- Context: Môi trường làm việc đang dùng (Hệ điều hành, phiên bản Docker, cổng kết nối...).
- Expected: Kết quả mong đợi khi chạy lệnh hoặc ứng dụng.
- Actual: Kết quả thực tế xảy ra (thông báo lỗi, treo ứng dụng...).
- Log: Đoạn mã lỗi chi tiết sao chép trực tiếp từ terminal.

## 2. Quy trình 3 bước tra cứu bắt buộc
1. Googling: Tìm kiếm lỗi trên Google với từ khóa chính xác.
2. Community Search: Kiểm tra các thảo luận trên Stack Overflow hoặc GitHub Issues.
3. AI Translation / Analysis: Dùng AI để phân tích thông báo lỗi và gợi ý cách khắc phục trước khi nhờ nhóm hỗ trợ.
